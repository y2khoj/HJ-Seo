# Live Vault 개발용 APK

`Live-Vault-standard.apk`: Live Vault, standard 마이크 전용, **2.3.0-preview / versionCode 8**, Android 9 이상.

2.2 기능을 유지하고 Galaxy S26 Ultra 비율에 맞춰 여백·파형·조절 영역을 재배치했습니다. 녹음·영상·연습의 주요 조작은 하단에 고정하고 시스템/키보드 영역과 확대 글씨를 반영합니다. 공통 다크 선택창, 테이크 일시정지·재개, 반주 구간 이동을 포함합니다. 하단은 라이브·반주·보관함 3개이며 보컬 연습은 전체 메뉴에서 엽니다. 승인된 이중 원호 마이크 벡터와 기존 레이턴시·예약 녹음·카메라·스피커 기능을 유지합니다. 다른 앱 오디오 캡처 구현과 권한은 포함하지 않습니다. [실제 뷰 렌더링과 검사 범위](../docs/GALAXY_S26_ULTRA_LAYOUT.md).

SHA-256은 `Live-Vault-standard.apk.sha256`에 기록합니다. 개발용 debug 서명이며 1.2 체크포인트와 앱 ID·서명이 같아 해당 버전을 업데이트할 수 있습니다. 개인용은 별도 앱 ID이며 공개 저장소에 올리지 않습니다.

`LiveMic-Pro-checkpoint.apk`와 `LiveMic-Pro-design-v2.apk`는 이전 버전 기록입니다. 이전 design-v2 APK는 다른 개발 키를 사용하므로 교체 전에 테이크를 내보내세요.

검증 범위는 `docs/STATUS.md`, 브랜드 적용은 `docs/BRANDING.md`를 확인하세요.
