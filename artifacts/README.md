# Live Vault 개발용 APK

현재 소스는 **3.9.0-preview / versionCode 27**이며 이번 산출물은 **personal 전용**이다. 개인용 오버레이·APK·키와 비공개 전달 URL은 공개 저장소에 포함하지 않는다. [태블릿 지원·APK 식별·검증 범위](../docs/LIVE_VAULT_V3_9_0_TABLET.md).

`Live-Vault-standard.apk`는 main `7ecfd97`에 있던 **3.6.0-preview / versionCode 16** standard 마이크 전용 개발 APK다. 이번 작업에서 APK 파일은 교체하지 않았다. 실제 SHA-256은 다음과 같으며 `.sha256` 파일의 이전 값을 바로잡았다.

```text
3ef89e3193c8235bc23080850b6eb06fc04ecba62ca35da20bfb89ac3b9e5732
```

이전 문서의 3.2.1 / `f844…` 값은 현재 공개 APK를 설명하지 않는다. [3.7 검증 기록](../docs/LIVE_VAULT_V3_7_VALIDATION.md)의 95개 검사는 당시 이력이다. 최신 개인용 APK의 식별 정보와 검증 범위는 [3.9.0 기록](../docs/LIVE_VAULT_V3_9_0_TABLET.md)을 확인한다. 실제 기기 오디오·장치·터치 접근성·지연은 검증하지 않았다.

`LiveMic-Pro-checkpoint.apk`와 `LiveMic-Pro-design-v2.apk`는 이전 버전 기록이다. 이전 design-v2 APK는 다른 개발 키를 사용하므로 교체 전에 테이크를 내보내야 한다.

전체 변경 이력은 [STATUS](../docs/STATUS.md), 브랜드 적용은 [BRANDING](../docs/BRANDING.md)을 확인한다.
