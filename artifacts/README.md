# Live Vault 개발용 APK

`Live-Vault-standard.apk`는 standard 마이크 전용 개발 APK의 전달 경로입니다. 현재 소스는 **3.2.1-preview / versionCode 12**, Android 9 이상입니다. 이 APK는 **3.2.1-preview / versionCode 12**이며 SHA-256은 `f84486dc562454b88f533ddd14fc6538fee8651974aff2737d0cb817991ff948`입니다. [3.2.1 검증 범위](../docs/LIVE_VAULT_V3_2_1_RECORDING.md).

SHA-256은 `Live-Vault-standard.apk.sha256`에 기록합니다. 실기기 동작은 아직 검증하지 않았습니다. 개인용은 별도 앱 ID이며 공개 저장소에 올리지 않습니다. 이전 3.1 체크포인트는 [명세](../docs/LIVE_VAULT_V3_1_SPEC.md)와 [검증](../docs/LIVE_VAULT_V3_1_VALIDATION.md)에 기록합니다.

`LiveMic-Pro-checkpoint.apk`와 `LiveMic-Pro-design-v2.apk`는 이전 버전 기록입니다. 이전 design-v2 APK는 다른 개발 키를 사용하므로 교체 전에 테이크를 내보내세요.

검증 범위는 `docs/STATUS.md`, 브랜드 적용은 `docs/BRANDING.md`를 확인하세요.
