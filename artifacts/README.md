# Live Vault 개발용 APK

`Live-Vault-standard.apk`: Live Vault, standard 마이크 전용, **3.1.0-preview / versionCode 10**, Android 9 이상.

실제 목소리 자동 화음과 최대 네 겹의 독립 오디오 루프를 추가했습니다. 다른 앱 오디오 캡처 구현과 권한은 포함하지 않습니다. [실제 뷰 렌더링과 검증 범위](../docs/LIVE_VAULT_V3_1_VALIDATION.md).

SHA-256은 `Live-Vault-standard.apk.sha256`에 기록합니다. 개발용 debug APK이며 기존 인증서와 서명이 일치함을 확인했습니다. 이 파일은 3.1 체크포인트 standard APK입니다. 실기기 동작은 아직 검증하지 않았습니다. 개인용은 별도 앱 ID이며 공개 저장소에 올리지 않습니다.

`LiveMic-Pro-checkpoint.apk`와 `LiveMic-Pro-design-v2.apk`는 이전 버전 기록입니다. 이전 design-v2 APK는 다른 개발 키를 사용하므로 교체 전에 테이크를 내보내세요.

검증 범위는 `docs/STATUS.md`, 브랜드 적용은 `docs/BRANDING.md`를 확인하세요.
