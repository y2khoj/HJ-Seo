# Public microphone checkpoint

`LiveMic-Pro-checkpoint.apk`: standard 마이크 전용 버전, 1.2.0-checkpoint, Android 9 이상.

즉시·3초·5초·10초 시작과 백그라운드 녹음, 알림에서 예약 취소/저장을 지원합니다. 휴대폰/블루투스 스피커 출력과 하울링 보호도 포함합니다. 외부 앱 소리 캡처 권한과 구현은 포함하지 않습니다. 개인용 APK는 이 공개 저장소에 올리지 않습니다.

개발용 debug 서명 APK입니다. 실제 기기의 오디오 지연·카메라 동기화·제조사별 동작은 미검증입니다. 최종 스토어 배포본이 아닙니다.

최신 APK의 SHA-256은 `LiveMic-Pro-checkpoint.apk.sha256`에 기록합니다.

검사 결과는 `docs/STATUS.md`, 사용 방법은 `docs/BACKGROUND_RECORDING.md`를 확인하세요.

`LiveMic-Pro-design-v2.apk`는 기존 디자인 v2 기록용 APK입니다. 예약 녹음/스피커 통합 최신본은 `LiveMic-Pro-checkpoint.apk`입니다.

기존 `LiveMic-Pro-design-v2.apk`는 다른 개발 키로 서명되어 직접 업데이트가 안 될 수 있습니다. 기존 v2를 제거하기 전에 테이크를 파일로 내보내세요. 개인용은 별도 앱 ID여서 기존 v2와 함께 설치할 수 있습니다.
