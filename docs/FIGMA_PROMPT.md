# Figma 디자인 브리프

Android 앱 “Live Vault”의 모바일 UI를 설계해줘. 노래하는 사람이 유선/USB 이어폰으로 리버브가 적용된 목소리를 실시간 모니터링하면서, 반주와 함께 오디오·MIDI·카메라 영상을 녹음하는 개인 보컬 스튜디오야.

412×915와 360×800 Android 화면에 맞춰 스튜디오 / 반주 / 실시간 MIDI / 카메라 / 보관함 5개 주요 화면을 만들어줘. 오디오 녹음 바와 타이머는 모든 화면 하단에 고정하고, 마이크 켜기/끄기와 모니터링 음소거 조작은 스튜디오 본문에만 넣어줘. 카메라는 전면·후면 미리보기, 영상 녹화, 촬영 후 MP4 오디오 결합 진행 상태가 필요해.

초기 방향은 차콜-그린 배경 #101411, 카드 #1C231E, 라임 포인트 #D0F56B, 기본 텍스트 #F0F3ED, 보조 #9BA99C, 녹음/위험 #FF7D7D. 전문 음악 도구처럼 정돈하되 처음 쓰는 사람도 이해할 수 있게 한국어 라벨을 써줘. 값·타이머·음정은 고정폭 숫자, 주요 조작 터치 영역은 48dp 이상으로.

프리셋 6개, 마이크/반주 믹서, 리버브·에코·3밴드 EQ·컴프레서, 팝·재즈·락·Jpop·Kpop 장르별 반주 곡 목록과 BPM/전조, 제목 옆 작은 지원 형식과 최근 불러온 목록이 있는 로컬 파일 반주, YouTube 외부 링크, 큰 현재 음정과 센트 미터·피아노 롤, 테이크별 WAV/MID/MP4 저장·공유를 포함해줘.

권한 미허용, 이어폰 미연결, 입력 대기, 녹음 중, 카메라 오류, 영상 저장 중, 빈 보관함 상태도 설계해줘. “마이크 끄기”와 “모니터링 음소거”는 서로 다른 동작이야. YouTube 오디오는 녹음에 포함되지 않아. 표시 지연은 출력 버퍼 값이며 실제 왕복 지연으로 표현하면 안 돼.

컴포넌트 variants와 변수/스타일을 먼저 정의하고 화면에 재사용해줘. 상세 명세는 docs/FIGMA_HANDOFF.md를 따라줘.

최신 시안은 docs/DESIGN_RESULT.md를 참고해줘. 영상 촬영 시작 시 오디오도 시작하고, 카메라 화면에 상단 REC 타이머와 코너 전·후면 전환, 일시정지/재개, 중단·저장 버튼을 넣어줘. 영상·오디오는 함께 일시정지하고 함께 저장해. 반주 목록은 수록 후보이며 현대 히트곡을 저작권 없는 곡으로 표시하지 마.
