# Live Vault 2.1 구현 명세

## 브랜드와 화면

영문 표시 이름 Live Vault / Live Vault Personal. 블랙 #0B0C0F, 카드 #1C1F26, 컨트롤 #292D36, 카드 테두리 #373E49 / 컨트롤 테두리 #454B57, 글자 #F4F6F8, 보조 #B8C0CC, 강조 #E7F500, 경고 #FF4D60. Noto Sans KR / Roboto Mono.

승인 로고는 마이크와 동심원 두 원호다. 바깥 L은 12→9→6→3시 반시계 270도, 안쪽 V는 9→6→3시 180도. 하단 겹침은 두 줄, 우측 상단은 열린다. SVG 원본은 design/brand/live-vault-mark.svg, 앱은 동일 경로의 VectorDrawable을 사용한다. JPG는 사용하지 않는다.

하단은 라이브·반주·보관함 세 개. 카메라는 라이브 하위 화면이다. 햄버거는 오디오 설정·녹음 설정·보컬 연습·도움말 네 항목이다. MIDI는 보컬 연습 안의 자유 음정 화면에 합친다. 오디오 녹음은 탭을 바꿔도 계속되고 녹화 중 이동은 저장 확인을 거친다. 전역 음소거는 출력만 차단한다.

라이브는 출력/프리셋 선택, 입력 레벨, 목소리 크기/리버브, 원형 마이크 버튼, 오디오/영상, 반주 순서다. 녹음 바는 라이브 또는 진행 중에만 표시한다. 반주는 소스 드롭다운과 실재하는 합성 반주/파일/외부 링크를 제공한다. 보관함은 WAV/MID/MP4와 연습 결과를 테이크 단위로 묶는다.

## 레이턴시와 싱크

AAudio 버퍼는 반응 우선 1 burst, 균형 2, 안정 4 및 수동 1~8단계. 실제 장치 용량으로 제한하며 실제 적용 버퍼 ms·프레임·xrun을 표시한다. 왕복 지연 측정값이나 Bluetooth 전송 지연 제거를 의미하지 않는다. 모드별 저장하며 녹음·예약·연습 중 변경을 막는다.

싱크는 다음 녹음에 적용하는 -500~+500ms/5ms, 기본 0. 음수는 반주 버스를 지연, 양수는 보컬 버스를 지연한다. 모니터링 경로는 영향을 받지 않는다. 종료 시 지연 tail을 배출하고 MIDI 노트에 보컬 지연을 더한다. 영상 PTS도 보컬 지연만큼 조정한다. 기존 혼합 파일을 재편집하거나 원음 stem을 추가 보관하지 않는다. 5초 메트로놈 테스트는 캐시에만 저장한다.

## 보컬 연습

듣고 따라: 안내 1박, 준비 0.5초, 발성 2박. 함께 부르기: 음당 2박, 첫 200ms 제외. 스피커/BT의 동시 가이드음은 꺼두며 화면 목표를 따른다. 분석은 클린 마이크에 수행한다.

5음 상하행/장음계 1옥타브, A2~C5 시작음, 40~120 BPM. 기본 C3·60 BPM·5음·4박 카운트. 센트는 1200 log2(현재Hz/목표Hz), ±25센트 기준이다. 75~1100Hz, 신뢰도 ≥0.85, RMS ≥0.007의 입력을 평가한다. 옥타브 오류를 반음 단위로 접지 않는다. 무음은 점수를 만들지 않는다. 정확도·평균절대오차·발성비율을 표시한다.

연습 녹음은 기본 OFF. ON이면 WAV·MID·노트별 결과를 한 테이크로 저장하며 가이드 출력은 디지털 녹음 버스에서 제외한다. 연습 녹음 싱크는 0. 앱 배경/페이지 이탈 시 부분 결과를 저장하고 안내음을 끈다. 연습이 소유한 마이크는 함께 종료한다.
