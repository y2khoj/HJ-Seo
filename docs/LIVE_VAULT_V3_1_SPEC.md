# Live Vault 3.1 — 보컬 화음과 레이어 (구현 체크포인트)

대상은 `3.1.0-preview / versionCode 10`이다. 검증 범위는 [검증 기록](LIVE_VAULT_V3_1_VALIDATION.md)을 참고한다. 기존 3.0의 작곡기와 MIDI 프레이즈는 유지하며 [3.0 명세](LIVE_VAULT_V3_SPEC.md)에 기록한다.

## 화면과 테마

- 작곡기와 목소리 기능을 기존 차콜·네온 옐로, 앱 폰트와 3탭 테마에 맞춘다. 기본 Android Spinner/SeekBar/AlertDialog 대신 테마 선택 시트와 페이더를 사용한다.
- 라이브, 목소리 악기, 보컬 연습에서 숨겨진 탭 9의 보컬 화음 화면으로 진입한다. S26 Ultra 기준 기본/130% 글씨와 고정 조작부를 고려한다.

## 실제 목소리 자동 화음

- 실제 마이크 신호를 2-head granular overlap-add 피치 변환으로 처리해 화음을 만든다. GM 정현파 합성이 아니며 포먼트 교정은 없는 프리뷰다.
- 12개 키, 5개 스케일과 위 3도, 위 3도+5도, 아래+위 3도, 위아래 옥타브 프리셋을 제공한다. dry/wet과 spread를 조절한다.
- 자동 화음은 기본 OFF, 마이크는 런타임에서 기본 OFF다. 깨끗한 마이크 입력 기반 보컬 MIDI와 채점은 기존 동작을 유지한다.

## 네 겹 오디오 루프

- 최대 4개의 독립 스테레오 WAV 레이어, 4/8마디, 40–240 BPM, 4/4·3/4·6/8을 지원한다. 한 마디 카운트인 후 녹음하며 재생 중 녹음은 다음 루프부터 시작한다.
- 현재 새 라이브 성부만 레이어에 기록한다. 기존 레이어와 반주는 다시 녹음하지 않는다. 레이어 동시 재생과 레벨·팬·뮤트, 재녹음 취소 시 이전 내용 보존, 한 단계 undo를 제공한다.
- Atomic JSON과 WAV로 재실행 복구한다. 레이어가 존재하면 타임스트레치가 없으므로 BPM·박자·길이 변경을 막는다. 저장 레이어 재생에는 마이크 권한이 필요하지 않다.
- 작곡기 MIDI 프레이즈와 별개의 실제 오디오 루프다. 카운트인과 가이드음은 디지털 믹스에서 제외한다. 긴급/피드백 라이브 모니터 음소거 중에도 녹음은 유지하며 기존 WAV·영상 믹스에는 실제 화음과 레이어가 포함된다.

실제 발성의 화음 품질, 지연 및 장시간 동작은 실기기 확인이 필요하다. 개인용 소스와 APK는 비공개로 유지한다.
