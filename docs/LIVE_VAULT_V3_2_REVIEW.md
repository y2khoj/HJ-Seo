# Live Vault 3.2 독립 리뷰

두 리뷰는 서로 다른 GPT-6 Astra 리뷰어가 독립적으로 수행했다. 지적 사항을 수정한 뒤 각 범위의 결과를 확인했다.

## 디자인 리뷰 — 통과

API 35 Robolectric의 실제 Android View를 412 × 893 창의 기본 및 130% 글씨 크기로 렌더링해 검토했다. 연주 느낌 설정 시트의 자연 높이, 빈 성부와 선택된 성부, 카운트인·녹음 상태, 이름이 긴 성부가 있는 화면, 고정 조작부와 3탭, 같은 화면에서 스크롤 유지를 살폈다.

리뷰에 따라 녹음 대기·진행 중에는 다른 성부를 선택하지 못하게 하고, 같은 화면 갱신의 스크롤 복원과 진행 막대 색상을 수정했다. 긴 이름은 표시 줄 수를 제한하고 녹음 상태와 마디·박을 이름보다 먼저 표시한다. 설정 시트의 필인 선택 상태와 간격도 정리했다. 소스와 화면 테스트 fixture에서 발견된 문제를 해결했다.

## 기능 리뷰 — 승인

독립 네이티브 검사를 포함해 44.1/48kHz 처리, 패턴 선택 우선순위, 워킹 베이스의 코드 시작음, Java와 네이티브의 기타 보이싱·스트럼 타이밍 일치, 믹스 기준을 확인했다. 리뷰에서 찾은 베이스 시작음, 패턴 우선순위 및 기타 보이싱과 타이밍의 불일치를 수정했다. 기타 보이싱은 12개 근음과 11개 코드 종류, 총 132개 조합의 Java/네이티브 비교 검사도 제공한다.

화면 이미지는 테스트 환경의 렌더링이고 실제 기기 캡처가 아니다. 리뷰와 합성 신호 검사는 실제 발성의 청취 평가, 마이크·Bluetooth 경로와 지연, 장시간 부하 또는 CPU 벤치마크를 대신하지 않는다. 빌드와 검사 결과는 [검증 기록](LIVE_VAULT_V3_2_VALIDATION.md)에 별도로 남긴다.
