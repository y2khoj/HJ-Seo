# Live Vault 3.2 preview: 연주와 보컬 루프

3.2.0-preview / versionCode 11은 3.1의 작곡기와 보컬 화음 위에 연주 표현과 녹음 조작을 개선한다. 기존 프로젝트의 버전 1 JSON을 유지하며 새 필드가 없는 파트는 연주 강도 55%, 자연스러운 타이밍 65%, 마무리 필인 켜짐을 기본으로 읽는다. 각 설정은 선택한 파트에만 적용되고 복제와 실행 취소에도 보존된다.

- 공통 그루브를 기준으로 타이밍을 조정한다. 자연스러운 타이밍을 최대로 하면 기본 변동은 최대 ±8ms이며 스네어 뒤로 밀기는 최대 5ms다. 저장된 seed가 벨로시티 변화를 재현한다.
- 기타와 건반은 인접 코드의 보이싱을 연결하고, 악기군에 따라 워킹 베이스, 8분음 아르페지오와 지속 연주를 사용한다. 드럼 필인은 기존 이벤트를 대체한다.
- 화음 처리는 10ms 제어 갱신, 80ms 홀드, 15ms wet/dry 스무딩, 두 화음 성부 헤드룸과 적응형 그레인을 사용한다. 포먼트 보정은 제공하지 않는다.
- 녹음 원본을 바꾸지 않고 루프 재생의 경계만 최대 5ms에 걸쳐 보정한다.
- 네 성부에 이름을 저장하고 카운트인, 현재 마디·박과 루프 진행을 표시한다. 녹음 대상이 대기·녹음 중일 때 선택을 고정하며 같은 화면 갱신 시 스크롤 위치를 유지한다.

기존 3탭, 로고와 색상 체계를 유지한다. 이전 3.1 범위는 [3.1 명세](LIVE_VAULT_V3_1_SPEC.md)에 기록되어 있다.
