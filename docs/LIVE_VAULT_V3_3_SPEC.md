# Live Vault 3.3 preview

3.3.0-preview / versionCode 13은 반주 작곡 화면, AI 파일 교환과 앱 언어 선택을 개선한 개인용 개발 버전이다.

- 반주 화면에서 작곡기·내 파일·온라인 소스를 선택하고, 작곡기의 파트·코드·악기·곡 순서와 재생 조작을 사용할 수 있다.
- **AI용 내보내기**는 현재 프로젝트와 선택적 요청을 ZIP으로 저장한다. ZIP에는 프로젝트 JSON, 편곡 설명, AI 요청문, 스키마, 파일 해시가 들어가며 오디오는 포함하지 않는다. 기기에서 저장할 위치를 선택한 뒤 ChatGPT 등 AI에 직접 첨부한다.
- AI가 돌려준 완전한 프로젝트 JSON을 **AI 수정본 불러오기**로 선택하면 내용을 검증하고 미리보기를 표시한다. 새 복사본으로 열기 전에 현재 프로젝트를 보관함에 저장한다. 잘못된 파일은 적용하지 않는다.
- 전체 메뉴의 **언어 / Language**에서 한국어와 영어를 선택할 수 있다. 선택은 기기에 저장되며 프로젝트 이름과 사용자 입력은 변경하지 않는다. 영상 촬영 중에는 녹화 종료 후 화면 언어가 갱신된다.
