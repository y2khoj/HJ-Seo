# Live Vault 3.4 preview

3.4.0-preview / versionCode 14는 라이브 화면을 하드웨어 콘솔 느낌으로 재구성한 개인용 개발 버전이다. 기존 로고와 라이브·반주·보관함 세 탭, 한국어·영어 선택 및 고정 녹음 조작을 유지한다.

상단 화면은 실제 마이크·출력 경로·모니터링 및 보호 음소거 상태, 입력 레벨·감지 음, 녹음 시간과 재생 중인 반주 위치를 표시한다. 마이크 켜기와 내 목소리 듣기는 별도 조작이며, 모니터링은 기존 출력 연결과 피드백 보호를 따른다.

여섯 노브는 기존 목소리 크기, 리버브 양과 잔향 길이, 에코 양·간격·반복을 조절한다. 위아래 드래그 또는 접근성 조작으로 값을 바꿀 수 있으며, 초기화는 이 여섯 값에만 적용된다. 프리셋, 보컬 화음과 반주 진입도 제공한다. 새로운 오디오 효과나 신호 처리는 추가하지 않았다.
