# Live Vault 3.7 라이브 대시보드 명세

**3.7.0-preview / versionCode 17 — 개인용 체크포인트.** 기준 소스는 main `7ecfd97`이다. 이번 APK 산출물은 personal 전용이며 공개 standard APK를 교체하지 않는다. 구현은 Sol (`gpt-6.1-sol`, medium), 최종 판단과 직접 화면 검토는 루트 에이전트가 담당했다. Astra 검토는 사용하지 않았다.

## 라이브 화면

승인 로고, 햄버거 전체 메뉴, 어두운 무광 배경과 네온 라임 색상을 유지한다. 설정은 단순하게 두고 실제 상태를 표시하는 LCD에 남는 높이를 배정한다.

- 상단: 전체 메뉴, Live Vault 로고, 목소리 모니터 음소거.
- 하나의 LIVE SESSION 패널: LCD, 소스·마이크 전원·모니터의 세 버튼, 마이크 게인.
- LCD: 독립된 실제 IN/OUT 분할 VU와 dB, 중앙 음 이름과 Hz, 실제 녹음 시간·상태, 모니터 켜짐/꺼짐 또는 보호 음소거. 여유 높이가 있는 LCD에는 실제 cents 눈금과 피치 마커를 표시한다.
- 반주 패널: 재생/일시정지, 실제 파일 이름 또는 작곡기 프로젝트 이름, 재생 시간 또는 현재 마디, 반주 게인.
- 보컬 효과 패널: 상세 버튼, 리버브와 에코 게인.
- 고정 하단: 녹음/종료와 영상. 메인에는 노브, 여섯 효과 카드, 공용 다이얼, 추가 메뉴 버튼을 두지 않는다.

메인 슬라이더는 총 네 개다. 마이크 p0은 0–200%, 반주 p1은 0–100%, 리버브 p2는 0–100%, 에코 p4는 0–80%다. 각 행은 왼쪽 이름, 가운데 트랙, 오른쪽 실제 백분율이며 조절 영역은 48dp다. 화면을 다시 그리거나 값을 동기화하는 동작은 파라미터를 쓰지 않는다.

## 표시 데이터

IN은 NativeAudio stats[3] RMS, OUT은 stats[4] RMS에서 dB로 변환한다. OUT은 앱의 전체 디지털 출력 믹스를 나타내며 목소리 전용 미터가 아니다. 마이크가 꺼지면 IN은 무음이지만 반주가 재생되면 OUT은 움직일 수 있다. 무음은 −∞ dB, 잘못된 수치는 안전한 무음으로 표시한다. 피치는 유효한 주파수 stats[0]이 있을 때만 표시하며 음 이름은 stats[2], cents는 stats[1]에서 읽는다.

VU의 감쇠와 피크 유지는 실제 샘플 이력을 사용한다. 장식용 LCD 격자와 피치 고리는 정적 벡터이며 가짜 파형이나 임의의 미터 애니메이션은 없다. REC 점멸은 실제 녹음 중에만 동작한다. 녹음 시간은 stats[8], 녹음·일시정지는 RecordingManager, 예약은 AudioService의 실제 상태를 따른다. 화면 애니메이션은 JNI를 다시 호출하지 않는다.

## 상세 효과와 소스

**상세 ▾**는 리버브 양·잔향·공간, 에코 양·간격·반복, 3밴드 EQ, 컴프레서, 소음 완화, 현재 프리셋과 효과 초기화를 제공한다. 프리셋 선택 전에 상세 창을 닫는다. 효과 초기화는 마이크·반주 게인, 모니터, 소음 완화 p19와 녹음 상태를 유지한다.

**소스 ▾**는 입력·출력 장치의 전체 이름과 선택 버튼, 모니터 설정, 내 파일·온라인·작곡기, 오디오 설정을 제공한다. 메인에는 짧은 장치 이름을 쓰고 접근성 설명과 선택 창에는 전체 이름을 제공한다. 입력과 출력 선택은 기존 저장 경로를 사용한다. 반주 파일 이름 행에서도 반주 소스를 고를 수 있다.

재생 버튼은 현재 작곡기 또는 파일을 일시정지·재개한다. 파일 재생은 마이크 권한을 요청하지 않는다. 녹음·예약 등 기존 설정 잠금 상태에서는 소스/장치 변경과 반주 전환을 막는다. 마이크 전원과 모니터는 독립된 상태 및 보호 음소거 해제 동작을 유지한다. 활성 마이크에서 모니터를 전환할 때는 캐시 p11 대신 실제 stats[21] 상태를 기준으로 삼는다. 녹음 설정은 **전체 메뉴 → 녹음 설정**에서 연다.

## 범위

이번 변경은 라이브 UI와 관련된 Activity 연결, 테스트 및 문서다. `7ecfd97`에서 상속한 네이티브 DSP·AAudio·오디오 라우팅 구현은 변경하지 않았다. 신규 AAudio 수정으로 설명하지 않는다. 개인용 오버레이·키·개인용 APK와 비공개 전달 URL은 공개 문서나 저장소에 포함하지 않는다.
