# Live Vault 3.7 검증 기록

**3.7.0-preview / versionCode 17, personal 전용.** main `7ecfd97`을 기준으로 라이브 대시보드를 구현했다. Sol (`gpt-6.1-sol`, medium)이 구현하고 루트 에이전트가 직접 소스와 네이티브 Skia 렌더를 검토했다. Astra 검토는 사용하지 않았다.

## 현재 확인 상태

최종 Gradle 테스트와 서명된 개인용 APK 빌드가 통과했다. 개인용 테스트는 **95개, 실패 0, 오류 0, 생략 0**이다. 정적 diff 검사도 통과했다. 활성 마이크에서 모니터의 표시와 다음 전환이 어긋나던 캐시 상태 의존을 제거하고 실제 엔진 stats[21]을 사용하도록 수정했으며 회귀 검사를 포함했다.

최종 생성·보관한 [화면 렌더](screenshots/v3.7/)는 한국어/영어 × 360×800/412×893 × 기본/130% 글씨의 8개 조합과 대기·최대값·라이브·녹음·일시정지·보호 음소거·예약·소스·상세의 9개 상태, 총 **72장**이다. 루트가 최종 한국어 412 기본 글씨 녹음 화면과 영어 360 130% 글씨 라이브 화면을 직접 검토했다. 작은 LCD에서는 선택적인 cents 눈금을 숨겨 녹음 시계와의 겹침을 해소했다. Android View를 native Skia로 렌더링하며 오디오와 상태는 격리된 테스트 fixture다. 실제 휴대폰 캡처나 실제 마이크 신호 검증 결과가 아니다.

회귀 검사 범위는 네 개 메인 슬라이더의 실제 파라미터 연결, 읽기 동기화 시 쓰기 방지, 독립 IN/OUT과 무음·비정상 수치, 유효 피치와 실제 녹음 시간·상태, 모니터/보호 상태, 소스·장치 선택 잠금, 상세 효과·프리셋·초기화, 마이크 권한 없는 파일 재생, 일시정지한 작곡기 재개 및 기존 화면 진입이다.

## 공개 APK 기준

공개 `artifacts/Live-Vault-standard.apk`는 main `7ecfd97`에 있던 **3.6.0-preview / versionCode 16** 파일을 그대로 유지한다. 실제 기존 파일의 SHA-256은 다음과 같다.

```text
3ef89e3193c8235bc23080850b6eb06fc04ecba62ca35da20bfb89ac3b9e5732
```

이전 체크섬 문구만 실제 파일에 맞게 바로잡았다. 이번 3.7 산출물은 personal 전용이며 standard APK를 교체하지 않는다. 이전 버전 문서의 3.2.1 APK·해시는 당시 이력이다.

## 남은 검증

실제 기기의 오디오 품질, 입력/출력 장치 전환, USB·Bluetooth·AAudio 경로, 터치 및 TalkBack 접근성, 왕복 지연, 음향 피드백과 보호, 카메라 싱크, 개인용 오디오 캡처, 장시간 녹음은 검증하지 않았다. 기본/130% 글씨 렌더는 실제 기기 화면 확대·접근성 검증을 대신하지 않는다.

네이티브 DSP·AAudio·오디오 라우팅은 `7ecfd97`에서 상속한 구현 그대로다. UI 검사나 기존 호스트 검사 이력으로 새 네이티브 결함 수정 또는 실기기 오디오 검증을 주장하지 않는다.
