# Live Vault 3.8.1 — 메인 리버브·에코 조절

**3.8.1-preview / versionCode 19, 개인용 APK만 제공.** Sol (`gpt-6.1-sol`, medium)이 구현·테스트 코드를 작성하고 루트가 직접 검수했다.

리버브 양과 에코 양은 일반 라이브 화면과 YouTube 재생 화면에서 항상 표시하고 조절한다. 잔향 길이, 에코 간격·반복, EQ, 컴프레서, 소음 완화, 리버브 공간, 프리셋과 초기화는 상세에서 설정한다. 상세 창의 중복된 리버브 양·에코 양 조절기는 제거했다.

일반 화면의 기존 네 개 슬라이더는 유지한다. YouTube 화면에서는 마이크/반주 게인을 나란히 배치하고, 리버브/에코와 상세 버튼도 한 줄에 배치했다. 네이티브 SeekBar의 48dp 터치 영역, 값 표시와 접근성 범위를 유지하며 LCD 110dp와 플레이어 220dp를 줄이지 않는다. 리버브는 기존 파라미터 2(0~100%), 에코는 4(0~80%)를 사용한다. DSP·서비스·녹음 경로·YouTube 정책 경계는 3.8에서 변경하지 않았다.

## 확인한 결과

- LiveConsole/YouTube 기능·화면 검사 **34개 통과**, 실패·오류·생략 0. [집계](validation/v3.8.1/ui-counts.json).
- YouTube 마이크 전용 녹음 중 두 효과를 조절해 각 파라미터만 바뀌고 값이 저장·표시·재진입 복구되는 것을 확인했다. 마이크/반주 게인, 모니터, 녹음 상태, 시스템 MUSIC/VOICE_CALL 볼륨과 YouTube 재생 명령은 유지된다.
- 상세의 잔향·간격·반복·세 EQ 조절기와 프리셋/초기화 접근을 확인했다.
- 한국어/영어 × 360×800/412×893 × 기본/130%의 8개 조합에서 온라인·동의·라이브·녹음·오류 **40장**, 일반 라이브 참고 **2장**을 보관한다. [렌더 42장](screenshots/v3.8.1/). 일반 화면은 기존 72개 상태 렌더 검사도 재실행했다.
- YouTube 라이브/녹음 화면의 두 효과 슬라이더와 상세 버튼이 가려지지 않고, 최소 터치 크기를 유지하며, 값의 잘림·스크롤 없이 들어오는지 검사했다. 루트는 한국어 360 130% 녹음, 영어 360 130% 녹음, 한국어 412 일반/YouTube 화면을 직접 확인했다.
- 개인용 APK의 버전·앱 ID·3 ABI·기존 서명 인증서를 확인했다. 공개 standard APK와 개인용 오버레이는 변경하지 않았다.

화면은 실제 Android View를 native Skia로 렌더링한 테스트다. 동영상 자리는 OFFLINE fixture이며 실제 영상 재생 또는 기기 음질 검증을 뜻하지 않는다. 실기기 터치·TalkBack·오디오·YouTube 재생과 배포 전 정책 검토 등 [3.8의 미검증 항목](LIVE_VAULT_V3_8_VALIDATION.md)은 유지한다.
