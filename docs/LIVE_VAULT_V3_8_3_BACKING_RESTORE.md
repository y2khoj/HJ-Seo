# Live Vault 3.8.3 — 반주 진입 복구

**3.8.3-preview / versionCode 21, 개인용 APK만 제공.** 기준 `31bf8ab` 위에 반주 선택 경로를 복구했다. Sol (`gpt-6.1-sol`, medium)이 구현·테스트 코드를 작성하고 루트가 직접 검수했다.

## 누락 원인과 복구

메뉴 정리 과정에서 **반주** 항목이 빠지고, 라이브 파일명 탭은 재생/일시정지로 바뀌었다. 선택한 반주가 없을 때 재생 버튼을 누르는 경로도 종료되어, 내 파일·온라인 반주 화면에 들어갈 수 없었다. 3.8.2 검수에서는 이 진입 누락을 놓쳤다.

- **전체 메뉴 → 반주**를 복구했다. 작곡기·보관함·오디오/녹음 설정·보컬 연습·화음·도움말의 이동 인덱스도 맞췄다.
- 라이브 반주 줄에 **반주 선택 ▾** 버튼을 표시한다. 이름을 눌러서도 선택·변경할 수 있으며, 별도 재생 버튼은 재생/일시정지를 담당한다.
- 반주가 없는 상태에서 재생을 누르면 선택 화면을 연다.
- **내 파일 · 작곡기 · 온라인** 세 소스와 마지막 선택을 유지한다. 파일 가져오기, 작곡기 AI 내보내기/가져오기, 온라인 플레이어에 접근할 수 있다.
- YouTube 화면에서는 기존 76×96dp 상세 영역을 **반주 선택 48dp / 상세 48dp**로 나눠 접근 버튼을 제공한다. 플레이어를 가리거나 새 세로 줄을 추가하지 않는다.
- 녹음·예약 중에는 반주 선택을 잠가 현재 세션과 소스를 유지한다.

## 확인한 결과

전체 개인용 Java/Robolectric **126개 통과**, 실패·오류·생략 0. [집계](validation/v3.8.3/java-counts.json).

새 진입 회귀 검사는 실제 메뉴 행과 화면 버튼을 눌러 아래 동작을 확인한다.

1. 반주 메뉴 → 세 소스 탭 → 라이브 복귀, 마지막 소스 유지.
2. 반주 항목 추가 후 다른 메뉴가 올바른 화면/설정 창으로 이동.
3. 빈 상태·파일 선택·일시정지한 작곡기에서 버튼/이름 선택이 재생을 시작하지 않고 선택 화면을 엶. 마이크 권한 요청 없음.
4. 빈 재생 버튼은 선택 화면을 열고, 파일을 선택한 뒤의 재생 버튼은 파일 재생을 수행.
5. YouTube 화면에서도 선택 버튼에 접근하고 내 파일로 전환 가능. 자동 동영상 재생 없음.
6. 녹음/예약 상태에서 선택 진입 시 현재 소스·반주·녹음 상태 유지.

기존 전체 회귀에는 하울링 경로/보호, 작곡기·파일 교환·저장·녹음·YouTube 검사도 포함한다. 네이티브 DSP·하울링·재생 엔진·개인용 캡처 오버레이는 이번 수정에서 변경하지 않았다.

한국어 360×800/130%와 영어 412×893/기본 글씨의 라이브·메뉴, 영어 반주 세 페이지 **7장**을 보관한다. [렌더](screenshots/v3.8.3/). 루트가 한국어 작은 라이브/메뉴와 영어 내 파일/작곡기 화면을 직접 확인했다. 기존 라이브/YouTube 화면 조합도 재실행해 선택/상세 버튼의 최소 48dp 및 플레이어 영역·겹침·스크롤을 확인했다.

화면은 Android View의 native Skia 테스트 렌더다. 실제 휴대폰 캡처나 실제 오디오 재생 검증을 뜻하지 않는다. 장치 오디오·YouTube·음향 하울링 관련 [3.8.2 실기기 미검증 항목](LIVE_VAULT_V3_8_2_FEEDBACK_REVIEW.md)은 유지한다.
