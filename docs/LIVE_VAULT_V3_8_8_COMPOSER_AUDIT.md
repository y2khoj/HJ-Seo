### 기존 프로젝트 호환과 기록 보존

`phraseSource`는 선택 필드이며 `microphone` / `keyboard`를 구분한다. 필드가 없는 예전 프로젝트도 그대로 읽고 내보내기/가져오기를 할 수 있다. 예전 기록의 출처를 추측해서 자동으로 덮어쓰지 않는다. 명시적인 마이크 트랙이 없고 8트랙이 모두 찼다면 기록 시작 전에 공간 부족을 알린다. 기존 기록을 지우거나 9번째 트랙을 만들지 않는다.

LLM용 `arrangement.md`와 `schema.json`도 실제 패턴 ID 및 선택 필드와 맞췄다. AI 가져오기는 이전과 같이 미리보기 후 새 복사본을 열며 현재 프로젝트를 먼저 저장한다.

루트 최종 검수에서 저장 완료 알림이 UI 버전 값을 바꿔 정상적인 진행 중 기록을 거부할 수 있는 경로도 발견했다. 실제 프로젝트 객체·내용과 고정 대상을 검사하도록 수정했다. 내용 변경 없이 저장만 완료된 경우에는 새 프레이즈를 정상 저장하고, 같은 객체라도 내용이 변경된 경우에는 이전 결과를 적용하지 않는 두 사례를 추가로 검사했다.

### 음악 처리 검수

추가 패턴은 4/4·3/4·6/8, 마디당 두 코드, 분수코드, 기타 음역, 노트 켜기/끄기 균형, 마디/코드 경계, 동일 시드 재현성을 검사한다. 패턴 변경은 기록한 프레이즈의 타이밍에 무작위 변화를 추가하지 않는다. `808 deep sustain`은 낮은 지속음이며 피치 글라이드를 구현했다는 의미는 아니다. 지원하지 않는 계열별 패턴 ID는 기본 0으로 재생한다.
