# Live Vault 3.9.0 — Galaxy Tab S9 Ultra 가로 화면

`3.9.0-preview / versionCode 27`, 개인용 APK. Galaxy Tab S9 Ultra의 14.6형·16:10 가로 사용을 위한 반응형 배치다. 구현은 Sol medium, 코드·검증·실제 View 렌더 검수는 루트가 수행했다. 기존 [3.8.8 작곡기 수정](LIVE_VAULT_V3_8_8_COMPOSER_AUDIT.md)을 포함한다.

## 사용 방법과 배치

같은 개인용 앱을 태블릿에 설치하고 가로로 사용한다. 실제 앱 창이 가로 840dp 이상이고 짧은 변이 600dp 이상이면 태블릿 배치를 사용한다. 시스템 바·카메라 노치 영역을 제외하며 키보드가 열리는 것만으로 화면 구성을 바꾸지 않는다. 해상도나 모델명을 하드코딩하지 않으며 DeX·분할 화면에서도 창 크기로 결정한다. 좁은 창과 세로 화면은 기존 단일 영역으로 돌아간다.

| 화면 | 가로 태블릿 배치 |
|---|---|
| 공통 | 기존 480dp 본문 제한을 풀고 최대 1600dp 안에서 넓은 작업 영역 제공. 상단에 라이브·작곡기·보관함 바로가기. 시스템 바와 하단 태스크바 여백 반영 |
| 라이브 왼쪽 | 큰 LCD에 IN/OUT 레벨·피크·음 이름·Hz·cents·녹음 상태/시간, 그 아래 마이크·모니터링·입출력 장치·마이크 볼륨 |
| 라이브 오른쪽 | 반주 이름·재생·반주 볼륨, 리버브·에코와 상세 설정. 남은 높이에 맞춰 효과 카드와 노브 확장 |
| 온라인 영상 | 기존 공식 플레이어를 오른쪽 반주 카드에 배치. 영상과 효과를 오른쪽에서 스크롤하며 LCD와 녹음 조작부 유지. 기존 가시성/일시정지·앱 내부 반주 볼륨 규칙 유지 |
| 작곡기 | 프로젝트·LCD 상태·키·템포·스케일·AI 파일 조작을 상단에 배치. 아래 왼쪽에 파트 화살표와 코드, 오른쪽에 악기 트랙·리듬·곡 순서. 두 영역이 각각 스크롤 |
| 목소리 악기 | 입력 음 → 출력 음 표시와 악기·연주 방식·파트·설정을 좌우로 배치. 프레이즈 기록과 재생/정지는 하단 고정 |
| 보관함·설정·기타 목록 | 내용 폭을 최대 880dp로 제한하여 긴 단일 행과 과도하게 넓은 입력 폼 방지 |

코드 카드의 4마디당 2×2 묶음, 대표 24 + 드럼, 키트 별 즐겨찾기, 파트 이전/다음 화살표, AI 내보내기와 JSON 가져오기는 유지한다. 악기 선택창은 태블릿에서 최대 760dp, 건반 입력창은 720dp로 제한한다. 효과·반주·녹음의 연결과 음악 처리 규칙은 바꾸지 않았다. 휴대폰의 기존 배치와 가로 뒤로가기 제스처를 방해하지 않는 효과 조작도 유지한다.

## 크기 변경 시 상태 보존

창 크기·회전으로 단일/태블릿 배치가 바뀔 때 화면만 다시 구성한다. 현재 페이지·소스·보관함 필터·프로젝트·선택 파트·볼륨·뒤로가기 방문 기록을 유지한다. 마이크·반주·녹음을 새로 시작하거나 종료하는 명령을 추가하지 않는다. 같은 배치 안에서의 크기 변경은 측정으로 처리한다.

카메라 페이지 또는 녹화 준비 중에는 연결된 TextureView와 카메라 컨트롤러를 다시 만들지 않는다. 미리보기 크기만 다시 측정하고 기존 카메라 경로가 화면 변환을 처리한다. 실제 기기의 카메라 센서·녹화 결과 검증은 별도로 필요하다.

LCD의 표시 연결은 기존 엔진 통계를 사용한다. 새 파형이나 무작위 레벨을 만들지 않으며, 기존 레벨 감쇠·피크 유지·녹음 표시 외에 상시 애니메이션을 추가하지 않는다.

## 화면·검증 증거

Robolectric/Skia가 실제 Android View를 렌더한 대표 창은 1480×924dp, 1280×800dp, 960×600dp다. 1480×924는 S9 Ultra 비율을 따른 테스트 창이며 실기기의 기본 dp 값을 측정한 결과는 아니다. 화면 확대 설정과 시스템 UI에 따라 실제 dp 값은 달라진다. 태블릿 화면은 대표 상태표시줄 24dp·하단 태스크바 48dp를 예약하고, 한국어/영어와 글씨 100%/130%를 검사한다. 휴대폰 412×893dp도 유지 여부를 확인한다.

이미지의 음높이·레벨·프로젝트는 명시적인 테스트 입력이다. 온라인 영상 이미지에는 **OFFLINE PLAYER FIXTURE**를 표시하며 실제 YouTube 네트워크 재생을 뜻하지 않는다.

전체 Java/Robolectric **213개 통과** 후 큰 글씨의 영어 반주 볼륨 문구가 실제 렌더에서 잘리던 부분을 보완했다. 태블릿에서만 이름/값 열의 폭을 늘리고 실제 네이티브 글꼴 레이아웃의 전체 글자·너비·높이·말줄임을 검사했다. 최종 영향 범위인 **라이브·온라인 영상·태블릿 43개 검사**와 개인용 APK 재빌드도 통과했다. 두 실행은 같은 항목을 일부 중복 검사하며 최신 고유 항목 수는 213개다. [전체 검사](validation/v3.9.0/full-java-counts.json) · [최종 영향 범위](validation/v3.9.0/final-ui-counts.json) · [검증 범위 설명](validation/v3.9.0/coverage.json).

두 영역 분리, 48dp 조작 영역, 16마디·8트랙의 독립 스크롤, 고정 녹음/재생 버튼, 실제 통계 연결, 드럼·별 즐겨찾기, 회전/분할 시 데이터·오디오 명령 보존을 검사했다. 온라인 영상은 오른쪽 영역에서 플레이어와 효과를 각각 완전히 표시할 수 있는지, 마이크 게인을 바꾸지 않고 반주 볼륨만 연결하는지 검사했다. 카메라는 회전 중 기존 TextureView/컨트롤러 참조를 유지하는 JVM 검사이며 실제 하드웨어 녹화 검증을 대신하지 않는다. 휴대폰 회귀와 언어 변경 검사도 통과했다.
