# Live Vault 3.0 — 작곡기와 목소리 악기

구현 대상: `3.0.0-preview / versionCode 9`. Java 화면, C++/AAudio, 기존 앱 ID·벡터 로고·테마·라이브/반주/보관함 3탭을 유지한다. 이 문서와 [검증 기록](LIVE_VAULT_V3_VALIDATION.md)은 구현 체크포인트이며 실기기 출시 승인이나 기존 서명 일치를 뜻하지 않는다.

## 화면과 사용

- 반주 → 소스 **내장 작곡기**. 내 반주를 열어도 같은 화면으로 이동한다.
- 키/스케일/BPM/박자 → 파트 → 4마디씩 2×2 코드 카드 → 악기 트랙 → 곡 순서.
- 작곡기 **목소리로 연주**, 보컬 연습 **목소리 악기**는 같은 화면이다. 입력 음과 악기 출력 음, 입력 dB, 악기·멜로디/코드 모드·기록할 파트를 표시한다.
- 재생/일시정지·정지·프레이즈 기록은 본문 스크롤 밖의 actionDock에 둔다. 상세 옵션과 악기 검색은 별도 대화상자/선택 시트다.
- 기본 C 메이저·90 BPM·4/4·8마디 A·C–G–Am–F 반복, 기타/베이스/드럼 ON·키보드 OFF.

## 음악과 프로젝트

- 12개 키와 메이저/자연 마이너/화성 마이너/도리안/믹솔리디안. 코드 기호와 도수를 함께 표시하고 수동 코드는 표시한다.
- 전조는 자동·수동 코드, 분수코드 베이스 및 프레이즈 MIDI 음을 함께 이동한다. 스케일 변경은 자동 코드만 재계산하고 수동 코드와 멜로디는 보존한다.
- 메이저·마이너·dim·aug·sus2·sus4·7·maj7·m7·m7♭5·add9 및 분수코드. 분수코드를 직접 지정하면 수동 코드로 취급한다.
- 한 마디 1/2코드. 분할은 4/4의 2+2, 3/4의 2+1, 6/8의 3+3개 8분음표다.
- 팝·발라드·캐논·재즈·마이너·마이너 종지 프리셋. 캐논은 8/16마디에서 사용한다. 메이저계열에서 마이너 프리셋을 고르면 자연 마이너로 바꾼다.
- 40–240 BPM. 6/8은 큰박 BPM을 받아 내부 4분음표 BPM으로 ×1.5 환산한다. 재생/리듬 선택은 사용자 BPM을 바꾸지 않는다.
- 팝 8/16비트·셔플·R&B·록·보사노바·왈츠·6/8 발라드. 박자에 맞는 리듬만 선택한다. 킥/스네어/하이햇 강약·열린 하이햇·마지막 마디 톰 필인을 포함한다.
- A–H 최대 8파트, 4/8/16마디, 전체 순서 최대 256마디. 순서 추가/이동/삭제와 반복 횟수를 편집한다. 구조 편집은 정지·일시정지 때만 허용한다.
- 파트별 코드·리듬·트랙 음색/패턴/볼륨/팬/뮤트/프레이즈. 키·스케일·BPM·박자는 곡 공통이다. 솔로는 저장하지 않는 미리듣기다.

## 악기와 목소리

- 최대 8트랙. GM 128음색, 16카테고리·검색·길게 눌러 즐겨찾기, 대표 24음색. 드럼은 로드한 SF2의 bank 128 프리셋을 열거한다.
- 기타는 6현 개방현 40/45/50/55/59/64와 최대 4프렛 손 위치를 사용한 스트럼/아르페지오/커팅/파워코드. 베이스는 28–55 범위에서 근음/5도/옥타브/코드톤 워킹을 재생하고 분수 베이스를 따른다.
- 건반/현악/패드는 블록·아르페지오·지속 코드, 관악/리드는 코드톤·롱톤을 제공한다. 자동 반주의 시간/강약 변형은 프로젝트 seed로 재현한다.
- 목소리 추적기는 보컬 MIDI 확정기와 별도 네이티브 스레드에서 10ms 홉/2048샘플 YIN 분석을 수행한다. 신뢰도 기본 .85, RMS 게이트 .007, 경계 ±70센트 유지, 2/3프레임 확정 및 강약 변화에 따른 재발음 검출.
- 자동 음역은 최초 음에서 옥타브를 고정한다. 베이스 음색을 선택하면 ON, 기타는 OFF. 수동 ±3옥타브. 스케일 맞춤 OFF가 기본이다.
- 멜로디의 피치 벤드/강약, 코드 모드의 강약을 반영한다. 코드 모드는 비브라토로 코드 피치를 흔들지 않는다. 코드 종류 자동/고정과 한 번 발음/파트 리듬을 선택한다.
- 목소리 연주가 작성된 코드 진행을 덮어쓰지 않는다. 원래 목소리 섞기는 기본 OFF이며 디지털 녹음 버스에도 이 선택을 반영한다.

## 프레이즈와 저장

- 정지 중에는 선택 파트 계획과 1마디 카운트인 후 기록한다. 재생 중에는 현재 파트의 다음 마디부터 끝까지 기록한다. 앞부분 쉼표는 파트 시작 기준 beat 오프셋으로 남긴다.
- 첫 완료 때 목소리 트랙을 추가하며 8트랙 한도를 넘기지 않는다. 이후 같은 파트의 목소리 트랙을 재기록한다. 완료 전에는 기존 프레이즈를 변경하지 않는다.
- 음표의 beat/length/MIDI/velocity, 코드 도수/종류/자동 여부, 스트럼 시차, bend/expression 곡선을 저장한다. 원음 파일은 프로젝트에 추가하지 않는다.
- 양자화 OFF/1/8/1/16. 기타 줄별 시차는 유지한다. 프레이즈 재생에는 추가 인간화 난수를 적용하지 않는다.
- 취소는 이전 연주를 유지하며 완료한 교체도 실행 취소/다시 실행 20단계로 복구한다.
- `files/composer/*.json`의 버전 1 프로젝트와 별도 draft.json. AtomicFile 교체로 마지막 완전 저장본을 보존한다. 저장/초안 복구/복제/이름 변경/삭제, 보관함 녹음/내 반주 필터, 기존 내장 반주 BPM/전조 설정 이전을 제공한다.
- 프로젝트 MIDI/WAV 내보내기와 음표 직접 편집은 제공하지 않는다. 기존 보컬 WAV/MIDI/영상 저장 경로는 유지한다.

## 오디오 경계

- `ComposerProject`, `TrackConfig`, `VoicePhrase`, `VoiceInstrumentSettings`, `ComposerTransport`, 전용 `NativeComposer` JNI. 기존 보컬 효과 파라미터 배열에 작곡기 설정을 넣지 않는다.
- GeneralUser GS SoftSynth **1.44** 원본 SF2와 README/CHANGELOG/원본 라이선스를 APK assets에 포함한다. 앱 실행 시 외부 다운로드는 없다. TinySoundFont의 저작권 문구도 assets에 포함한다. [출처와 해시](THIRD_PARTY_AUDIO.md).
- `tsf_copy`로 샘플/프리셋 데이터를 공유하는 두 인스턴스, 반주 80/목소리 16 발음 사전 할당. 채널도 출력 시작 전에 만든다.
- Java 작업 스레드에서 프로젝트 스냅샷과 정렬 이벤트를 생성한다. 네이티브 3슬롯 계획의 소유권을 atomic으로 교환하며 이전 계획 벡터 재할당은 게시 작업에서만 한다. 콜백은 파일/JSON을 읽거나 이벤트 벡터를 할당하지 않는다.
- 화성/템포/리듬 변경은 다음 마디에 계획을 교환한다. 트랙 볼륨/팬/뮤트는 atomic 목표와 부드러운 게인 전환으로 즉시 반영한다.
- 서비스의 미디어 재생은 출력 스트림만 연다. 마이크 권한은 실제 마이크/목소리 악기를 켤 때 요청한다. 입력은 출력 스트림을 닫지 않고 합류·종료한다. 프로세스 재실행 시 목소리 악기를 자동으로 켜지 않는다.
- 긴급 음소거는 보컬·목소리 악기 모니터링을 끄며 녹음 믹스는 유지한다. 하울링 보호는 두 모니터를 합친 신호에 적용한다. 카운트인/연습 가이드는 출력에만 더한다. MIDI/채점 분석은 계속 클린 입력을 받는다.
