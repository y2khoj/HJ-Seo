# 제품 범위

## 목표

유선 이어폰만 연결한 Android 휴대폰을 개인 보컬 연습·아이디어 녹음·노래 영상 촬영 도구로 만든다. 효과가 적용된 내 목소리를 들으면서 오디오와 단선율 MIDI를 저장하고, 카메라를 켜면 같은 보컬 믹스를 영상에 넣는다.

## 플랫폼 결정

초기 HTML/웹앱 PRD에서 Android 네이티브 APK로 변경되었다. UI와 네트워크 상태에 영향받지 않는 오디오 콜백이 필요하므로 AAudio와 C++ DSP를 사용한다. 사용자 요청으로 카메라 미리보기와 영상 녹화를 추가했다. PWA 설치 및 웹에서 APK 만들기 화면은 현재 제품 범위에서 제거한다.

## 기능

- 입력: 휴대폰 기본 마이크 또는 사용자가 선택한 Android 입력 장치
- 출력: 유선/USB 이어폰 모니터링; 게인과 반주 볼륨 분리
- 효과: 6개 프리셋, 알고리즘 리버브/딜레이, 3밴드 EQ, 컴프레서, 소음 완화
- 반주: 4개 장르 합성 밴드, 템포, -6~+6 반음 전조, 메트로놈
- 로컬 반주: Android가 디코딩할 수 있는 모노/스테레오 파일, 현재 최대 8분
- 채보: 보컬 75~1,100Hz, 노트·주파수·센트, 최근 12초 피아노 롤, MIDI 저장
- 녹음: 효과 보컬 + 내장/로컬 반주 → WAV; 같은 구간 → MID
- 촬영: 전면/후면 Camera2, 최대 720p H.264, 처리된 오디오를 AAC로 합친 MP4
- 보관함: 테이크 이름, 재생, 파일별 저장, 공유, 삭제

## 중요한 한계

배포용은 마이크 전용이다. 개인용은 Android 10 이상의 공식 AudioPlaybackCapture를 선택할 수 있으며, 대상 앱이 허용한 오디오만 녹음에 섞는다. 보호·차단 설정을 우회하지 않는다. YouTube 외부 링크 재생과 앱 내 임베드는 별개의 기능이며 후자는 미구현이다.

단선율 음정 인식은 악보 완성 기능이 아니다. 잡음, 반주 유입, 비브라토, 자음으로 오인식할 수 있다. 물리적 입출력 지연은 기기별로 달라 실제 기기에서 측정해야 한다.

## 오디오 경로

```text
마이크 → HPF → 게인 → 3밴드 EQ → 컴프레서/소음 완화
                                  ├→ Dry
                                  ├→ Reverb
                                  └→ Delay
마이크(클린) → YIN → Pitch / MIDI / 선택적 신스
내장 밴드 또는 로컬 반주 ────────────┐
보컬 효과 + 선택적 신스 ────────────┼→ WAV 녹음
                                   └→ 이어폰 출력(보컬 모니터링 스위치 별도)
Camera2 → H.264 영상 + WAV→AAC → MP4
```

모니터링 음소거는 이어폰으로 나가는 보컬만 차단한다. 처리된 보컬은 녹음 파일에는 계속 포함된다. 마이크 끄기는 실제 스트림과 녹음까지 중지한다. 두 동작을 UI에서 구분해야 한다.
