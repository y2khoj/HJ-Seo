# 휴대폰 마이크 → 스피커 출력

standard(마이크 전용 배포용)과 personal(내부 오디오 선택 가능 개인용) 모두에 포함한다.

## 사용

스튜디오의 보컬 입력 카드 하단 **출력 설정**을 누르고, 팝업의 **출력 모드**에서 선택한다. 스피커 게인과 보호 음소거 해제도 이 팝업에 둔다.

- 이어폰: 기존 동작. 유선/USB 출력이 있어야 실시간 마이크 출력 가능.
- 휴대폰 스피커: 휴대폰 내장 마이크 → 휴대폰 스피커.
- 블루투스 스피커: Android 설정에서 스피커를 연결한 뒤 목록에서 선택. 휴대폰 내장 마이크 → 해당 A2DP/BLE 스피커.

마이크를 켜고 **모니터링**을 켠다. 실행 중 출력 경로를 변경하면 마이크 출력은 꺼진 상태로 준비되므로 다시 스위치를 켠다. 스피커 모드는 18% 모니터링 게인에서 시작하고 최대 65%로 제한한다. 이는 휴대폰 시스템 스피커 볼륨과 별개다. 시스템 볼륨도 낮게 시작해야 한다.

실행 중 경로 변경은 오디오 세션을 다시 연다. 녹음/예약 중에는 경로를 바꿀 수 없다. 변경 전 필요한 MIDI 채보는 저장한다.

## 경로 및 기기 효과

스피커 모드의 입력은 내장 마이크로 고정한다. 블루투스 마이크/SCO 통화 경로로 전환하지 않는다. 블루투스는 A2DP 또는 BLE 스피커의 미디어 경로를 사용하므로 지연이 있다. 초저지연/무지연을 보장하지 않는다.

휴대폰 스피커는 communication mode와 built-in speaker communication device를 사용한다. 스피커 모드의 입력 세션에는 지원되는 AcousticEchoCanceler와 NoiseSuppressor를 연결하고, 사용 가능한 자동 게인은 끈다. 효과 지원과 품질은 제조사·장치·경로마다 다르다. AEC ON 표시는 효과 API가 활성 상태라는 뜻이며 실제 에코 제거 성능 측정치는 아니다.

요청한 출력/입력 ID와 열린 AAudio 장치 ID가 일치하지 않으면 시작을 거부한다. 잘못된 기본 스피커 경로로 임의 대체하지 않는다. 블루투스 연결 해제 또는 오디오 오류 시 마이크 출력을 먼저 음소거한다. 블루투스 장치가 해제되면 진행 중 파일을 저장하고 서비스를 종료한다.

## 소프트웨어 피드백 보호

- 낮은 시작 게인과 모니터링 게인 상한
- 600–8,000 Hz 범위의 좁은 대역이 시간에 따라 커지는 패턴을 감지
- 의심 주파수에 최대 4개 노치 필터 적용
- 큰 입력이 연속 감지되거나 반복적으로 피드백 의심 주파수가 발생하면 모니터링 자동 음소거
- 스피커 모니터링 보컬의 출력 피크 제한
- **보호 음소거 해제**는 사용자가 누를 때만 수행하고 18% 게인으로 돌아감

분석은 마이크 실시간 출력이 켜져 있을 때 수행한다. 보호가 걸려도 WAV/MIDI 녹음은 계속되며, 모니터링 출력만 차단한다. 필터는 현재 세션 동안 유지하고 명시적 초기화 또는 새 세션에서 지운다.

합성 톤의 성장·과부하·무음 및 필터 감쇠는 호스트 테스트로 검사한다. 실제 방/스피커/휴대폰의 음향 피드백을 완전히 제거한다고 보장하지 않는다. 큰 목소리나 악기음이 피드백으로 오인식될 수 있다. 마이크와 스피커 거리, 방향, 시스템 볼륨이 결과에 큰 영향을 준다.

## 추가 실기기 확인 필요

- 휴대폰 스피커 선택 및 Android 9 / 12+ 통신 경로
- A2DP/BLE 스피커별 라우팅, 지연, 연결 해제 동작
- 제조사별 AEC/NS/AGC 효과 지원
- 실제 음향 피드백, 필터 오탐, 소음·발성 변화에 대한 동작

공식 참고: [AAudio NDK](https://developer.android.com/ndk/reference/group/audio), [AudioManager](https://developer.android.com/reference/android/media/AudioManager), [출력 변경](https://developer.android.com/media/platform/output).
