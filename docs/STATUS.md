# Checkpoint status

이 문서는 요청 시점의 작업 범위와 검증 상태를 기록합니다. 최종 출시본이 아닙니다.

## 작성된 모듈

- AAudio 입력/출력, 출력 콜백과 분석/파일 쓰기 스레드 분리
- 3밴드 EQ, 소음 완화, 컴프레서, 알고리즘 리버브, 피드백 딜레이
- 보컬 음정 분석, 노트 추적, SMF MIDI 인코더
- 내장 합성 밴드, PCM 로컬 반주 재생
- WAV 녹음, 테이크 메타데이터, 파일 저장/공유
- Camera2 전면·후면, H.264 녹화, WAV→AAC→MP4 결합
- Android 권한, 마이크 foreground service, 이어폰 분리 시 모니터링 차단
- 기능 연결용 native UI; 최종 시각 디자인은 미확정
- Figma 화면 명세와 디자인 브리프

## 확인된 검사

- Android NDK arm64 컴파일러의 `engine.cpp` 구문 검사 통과
- 호스트 C++ 테스트 통과: 44.1/48kHz 음정, 무음, MIDI 헤더/트랙, 링 버퍼 경계, DSP 안정성 및 리버브 잔향

## 진행 중

- 전체 Gradle APK 빌드 및 Android 런타임 스모크 테스트
- 에뮬레이터 시작

## 아직 검증하지 못한 항목

- 실제 기기의 마이크→이어폰 왕복 지연
- USB·3.5mm·내장 입력 장치별 라우팅
- 제조사별 Camera2 지원과 영상/처리 오디오 동기화
- 장시간 녹음과 저장 공간 부족, 전화/다른 앱의 오디오 선점
- Android 13/14/15에서 권한·foreground service·백그라운드 복구
- 프로세스 강제 종료 후 영상 임시 파일 복구

## 남은 제품 작업

- Figma 최종 디자인과 native UI 일치 작업
- 내장 밴드/로컬 파일의 재생 위치 및 반복 UI
- YouTube 앱 내 임베드 및 차단 시 대체 UI (현재 외부 열기만 구현)
- 공개 배포용 소유자 서명키와 정식 release 빌드

## 변경된 PRD 항목

- 웹/PWA/웹 APK 변환 기능은 네이티브 APK로 대체
- 오디오 저장은 손실 없는 WAV; 영상은 H.264 + AAC MP4
- 리버브는 IR convolution 대신 저지연 알고리즘 방식
- 자기상관 대신 YIN 기반 단선율 피치 검출
- 0ms / 오류 0% 보장 문구를 제거하고 측정 가능한 상태를 표시
