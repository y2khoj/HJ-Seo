# Checkpoint status

이 문서는 요청 시점의 작업 범위와 검증 상태를 기록합니다. 최종 출시본이 아닙니다.

## 현재: 2.1.0-preview / versionCode 6

승인 로고의 SVG·VectorDrawable은 유지하고 라이브·반주·보관함·전체 메뉴의 실제 네이티브 UI를 다시 구성했다. 눈금 슬라이더, 금속 다이얼, 아이콘 3탭, 최근 반주 미니 플레이어, 저장 WAV/MIDI/영상에서 읽는 미리보기와 형식 배지를 적용했다. [실제 코드 렌더링과 변경 내용](UI_REFRESH.md).

- standard/personal debug APK 빌드 성공, 3개 ABI 유지.
- Android API 28 + 네이티브 Skia View 렌더링 검사 통과: 360/412 너비, 녹음 버튼/탭 겹침 방지, 슬라이더 접근성 조절과 실제 파라미터 연결, MIDI 미리보기 노트 파싱.
- 기존 호스트 DSP/피드백/캡처 버스, 예약 녹음, 녹음 싱크와 보컬 채점 검사 통과.
- 기존 2.0과 동일한 개발 서명 및 standard/personal 캡처 구현 분리 확인. Robolectric 테스트 의존성과 샘플 데이터는 APK에 포함되지 않는다.

보관한 PNG는 실제 앱 View 코드의 렌더링이며 오디오 하드웨어를 대체한 시각검사용 샘플 데이터를 사용한다. 실기기 스크린샷이나 실음성 검증 결과가 아니다. Android 11 에뮬레이터 재시도는 System UI ANR과 APK 설치 시간 초과로 중단됐다. 이번 버전의 실기기 마이크·카메라·Bluetooth 검증 및 확대 글꼴 검증은 남아 있다.

기존 원격 디자인 v2(`562c11f`)의 UI·최근 반주·카메라 전환/일시정지 및 MIDI 시간 보정과 통합했습니다.

## Android 런타임 검사

예약 녹음·스피커 기능 빌드(디자인 v2 통합 전)는 Android 11 x86_64 에뮬레이터에서 standard / personal 모두 다음 검사를 통과했다.

- 3초 예약 후 홈 화면으로 전환 → 백그라운드 녹음 시작
- 녹음 저장 → WAV 본문, MIDI 파일, 테이크 메타데이터 생성
- 5초 예약 취소 → 원래 시각이 지난 뒤에도 녹음/테이크 생성 없음
- 휴대폰 스피커 경로 열기 및 낮은 기본 게인 확인
- 배포용의 내부 오디오 캡처 권한/기능 제외 확인

앱 UI 갱신은 화면이 보일 때만 수행한다. 리버브 피드백 계수는 파라미터 변경 시에만 계산한다. 녹음 정상 종료 시 복구 루틴을 다시 실행하지 않는다.

디자인 v2 통합본은 두 APK·테스트 APK 빌드, 비공개 오버레이 없는 공개 소스 빌드, 호스트 DSP/예약/MIDI 시간축 검사를 통과했다. 통합본 에뮬레이터 재검사는 Android WindowManager 오류와 PackageManager 서비스 부재로 APK 설치 전에 중단되었다. 따라서 최신 통합본의 런타임 재검증은 남아 있다. 통합 UI의 실제 촬영·마이크/이어폰 품질과 시스템 오디오 캡처는 별도 기기 검증이 필요하다.

## Live Vault 1.3 UI·브랜드 변경

- 표시 이름 라이브볼트 / 화면 영문명 Live Vault, 제공된 LV 원본 JPG로 런처·상단 로고 변경
- 사용자 지정 UI 코드 MainActivity.java·StudioTheme.java 유지
- 스피커 설정을 출력 설정 팝업으로 옮겨 스튜디오의 원래 카드 순서 유지
- 녹음 시작 설정을 하단 ⋯ 버튼으로 배치
- Noto Sans KR·Roboto Mono 실제 폰트 포함, Android 기본 버튼 그림자·글자 간격 제거
- 앱 ID·콘텐츠 URI·보관함 경로는 유지
- 원본 Figma 재조회는 계정 MCP 호출 한도로 제한됨; 픽셀 단위 대조는 미완료

1.3 standard/personal APK 빌드가 통과했다. 두 APK의 표시 이름·버전(4 / 1.3.0-checkpoint), 로고 원본 바이트, 포함 폰트·라이선스, 내부 캡처 구현/권한 분리 및 기존 1.2와 동일한 개발 서명을 검사했다. 공개 APK는 약 7.1 MB이며 개인용은 비공개 Drive 파일로만 전달한다.

새 에뮬레이터에서 PackageManager 준비까지 확인했으나 APK 설치·화면 캡처 도중 작업 환경 연결이 종료되었다. 재연결 뒤 소스와 산출물은 유지됐지만 에뮬레이터 프로세스와 실행 세션은 종료되어 360/412 너비의 최종 화면 캡처는 미완료다. 이번 버전의 실제 런타임/시각 검증을 통과한 것으로 기록하지 않는다.

## 2.0 preview 구현·검증

3탭·햄버거 통합, 원호 SVG/VectorDrawable, 네온 옐로 테마, 출력 버퍼 조절, 녹음 버스 ±500ms 지연과 tail 배출/MIDI·영상 PTS 보정, 두 스케일 모드·피치 그래프·채점·선택적 연습 녹음/결과 저장을 구현했다.

standard/personal 및 instrumentation APK 빌드 통과. 기존 DSP·예약 테스트와 새 싱크(44.1/48kHz, ±500/250/0ms)·채점(정음/옥타브/무음/신뢰도/경계/지연 샘플) 테스트 통과. APK 서명·버전·벡터 포함·JPG 제거·개인용 분리 검사 통과.

Android 11에서 앱 화면 렌더링을 확인했으나 System UI 응답 없음 창이 캡처를 가렸다. 따라서 최종 시각 대조 통과로 기록하지 않는다. 실제 마이크/블루투스 지연, 가이드음 유입, 카메라 싱크, 장시간 녹음은 실기기 검증이 남아 있다.
