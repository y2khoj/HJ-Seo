# Checkpoint status

이 문서는 요청 시점의 작업 범위와 검증 상태를 기록합니다. 최종 출시본이 아닙니다.

## 작성된 모듈

- AAudio 입력/출력, 출력 콜백과 분석/파일 쓰기 스레드 분리
- 3밴드 EQ, 소음 완화, 컴프레서, 알고리즘 리버브, 피드백 딜레이
- 보컬 음정 분석, 노트 추적, SMF MIDI 인코더
- 내장 합성 밴드, PCM 로컬 반주 재생
- WAV 녹음, 테이크 메타데이터, 파일 저장/공유
- Camera2 전면·후면, H.264 녹화, WAV→AAC→MP4 결합
- Android 권한, 마이크 foreground service, 이어폰 분리 시 모니터링 차단
- Figma 시안 v2 기반 네이티브 카드·프리셋·믹서·고정 녹음 바·5개 탭
- 최근 반주 파일 URI 기록·재선택, 접근권한 저장, 목록 제거
- 카메라 REC HUD, 영상·오디오 일시정지/재개, 녹화 중 렌즈 전환 경로
- Figma 화면 명세와 디자인 브리프

## 확인된 검사

- 디자인 v2 전체 Gradle `:app:assembleDebug :app:lintDebug` 성공 (3개 ABI 포함)
- APK `apksigner verify` 서명 검사 통과
- Android NDK arm64 컴파일러의 `engine.cpp` 구문 검사 통과
- 호스트 C++ 테스트 통과: 44.1/48kHz 음정, 무음, MIDI 헤더/트랙, 링 버퍼 경계, DSP 안정성 및 리버브 잔향, 일시정지 구간 제외·경계 분할 MIDI 타임라인

## 디자인 v2 검증 범위

- `artifacts/LiveMic-Pro-design-v2.apk`: 버전 1.1.0-design-v2, 빌드·Lint·서명 검사 통과.
- 현재 연결된 Android 기기나 실행 가능한 에뮬레이터가 없어 새 APK의 화면·파일 권한·실제 촬영 스모크 테스트는 미실행.
- 일시정지 및 전·후면 전환의 영상·오디오 동기화, 렌즈별 방향과 해상도 호환성은 실기기 검증 필요.
- 새 개발 서명은 이전 체크포인트와 다름. 덮어설치 불가. 기존 앱 삭제 전 녹음을 외부 파일로 저장해야 함.

## 이전 체크포인트 런타임 검사 제한

- Android 11 x86_64 에뮬레이터에 APK 설치 성공
- 소프트웨어 에뮬레이션이 느려 앱 실행·화면·녹음 스모크 검사는 완료하지 못함
- 체크포인트 APK는 빌드/서명/설치 검사만 통과했으며 최종 사용성·기기 검증 전 개발 버전

## 변경된 PRD 항목

- 웹/PWA/웹 APK 변환 기능은 네이티브 APK로 대체
- 오디오 저장은 손실 없는 WAV; 영상은 H.264 + AAC MP4
- 리버브는 IR convolution 대신 저지연 알고리즘 방식
- 자기상관 대신 YIN 기반 단선율 피치 검출
- 0ms / 오류 0% 보장 문구를 제거하고 측정 가능한 상태를 표시
