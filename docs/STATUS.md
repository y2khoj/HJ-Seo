# Checkpoint status

이 문서는 요청 시점의 작업 범위와 검증 상태를 기록합니다. 최종 출시본이 아닙니다.

기존 원격 디자인 v2(`562c11f`)의 UI·최근 반주·카메라 전환/일시정지 및 MIDI 시간 보정과 통합했습니다.

## 작성된 모듈

- AAudio 입력/출력, 출력 콜백과 분석/파일 쓰기 스레드 분리
- 3밴드 EQ, 소음 완화, 컴프레서, 알고리즘 리버브, 피드백 딜레이
- 보컬 음정 분석, 노트 추적, SMF MIDI 인코더
- 내장 합성 밴드, PCM 로컬 반주 재생
- WAV 녹음, 테이크 메타데이터, 파일 저장/공유
- Camera2 전면·후면, H.264 녹화, WAV→AAC→MP4 결합
- Android 권한, 마이크 foreground service, 이어폰 분리 시 모니터링 차단
- Activity와 독립적인 즉시/3/5/10초 예약 녹음, 알림에서 예약 취소·녹음 저장
- standard(마이크 전용) / personal(선택적 내부 오디오) flavor 분리
- 개인용 AudioPlaybackCapture: 공식 사용자 동의, 자체 UID 제외, 녹음 버스에만 믹싱
- 디자인 v2의 네이티브 UI와 예약 녹음·스피커 출력 조작 통합
- Figma 화면 명세와 디자인 브리프
- 이어폰/휴대폰/블루투스 출력 모드, 내장 마이크 고정, 지원 AEC/NS 및 피드백 억제·자동 음소거

## 확인된 검사

- Gradle standard/personal debug APK 및 두 instrumentation APK 빌드 성공 (앱은 3개 ABI 포함)
- 개인용 오버레이가 없는 공개 소스 구성의 standard 독립 빌드 통과
- APK `apksigner verify` 서명 검사 통과; 기존 체크포인트와 동일한 개발용 서명
- standard APK에 MediaProjection 권한과 Playback 구현 클래스가 없고 personal에만 포함되는지 검사 통과
- 합성 신호 보호 검사: 무음 안정성, 성장 톤 노치 감쇠, 큰 입력 자동 음소거 및 명시적 리셋 통과
- Java 카운트다운 회귀 검사: 0/3/5/10초 경계, 취소, 재예약, 중복/잘못된 요청 검사 통과
- Android NDK arm64 컴파일러의 `engine.cpp` 구문 검사 통과
- 호스트 C++ 테스트 통과: 44.1/48kHz 음정, 무음, MIDI 헤더/트랙, 일시정지 구간을 제외한 WAV/MIDI 시간축, 링 버퍼 경계, DSP 안정성 및 리버브 잔향, 내부 오디오 스테레오 믹스/게인/무음/비활성 버퍼

## Android 런타임 검사

예약 녹음·스피커 기능 빌드(디자인 v2 통합 전)는 Android 11 x86_64 에뮬레이터에서 standard / personal 모두 다음 검사를 통과했다.

- 3초 예약 후 홈 화면으로 전환 → 백그라운드 녹음 시작
- 녹음 저장 → WAV 본문, MIDI 파일, 테이크 메타데이터 생성
- 5초 예약 취소 → 원래 시각이 지난 뒤에도 녹음/테이크 생성 없음
- 휴대폰 스피커 경로 열기 및 낮은 기본 게인 확인
- 배포용의 내부 오디오 캡처 권한/기능 제외 확인

앱 UI 갱신은 화면이 보일 때만 수행한다. 리버브 피드백 계수는 파라미터 변경 시에만 계산한다. 녹음 정상 종료 시 복구 루틴을 다시 실행하지 않는다.

디자인 v2 통합본은 두 APK·테스트 APK 빌드, 비공개 오버레이 없는 공개 소스 빌드, 호스트 DSP/예약/MIDI 시간축 검사를 통과했다. 통합본 에뮬레이터 재검사는 Android WindowManager 오류와 PackageManager 서비스 부재로 APK 설치 전에 중단되었다. 따라서 최신 통합본의 런타임 재검증은 남아 있다. 통합 UI의 실제 촬영·마이크/이어폰 품질과 시스템 오디오 캡처는 별도 기기 검증이 필요하다.

## 아직 검증하지 못한 항목

- 실제 기기의 마이크→이어폰 왕복 지연
- 휴대폰/블루투스 출력 경로 및 실제 음향 하울링 억제, AEC 효과와 무선 지연
- USB·3.5mm·내장 입력 장치별 라우팅
- 제조사별 Camera2 지원과 영상/처리 오디오 동기화
- 장시간 녹음과 저장 공간 부족, 전화/다른 앱의 오디오 선점
- Android 13/14/15에서 권한·foreground service·백그라운드 복구
- 개인용의 실제 MediaProjection 권한 승인 후 외부 앱 캡처, 앱별 허용 여부 및 보컬/반주 정렬
- 프로세스 강제 종료 후 영상 임시 파일 복구

## 변경된 PRD 항목

- 웹/PWA/웹 APK 변환 기능은 네이티브 APK로 대체
- 오디오 저장은 손실 없는 WAV; 영상은 H.264 + AAC MP4
- 리버브는 IR convolution 대신 저지연 알고리즘 방식
- 자기상관 대신 YIN 기반 단선율 피치 검출
- 0ms / 오류 0% 보장 문구를 제거하고 측정 가능한 상태를 표시

## Live Vault 1.3 UI·브랜드 변경

- 표시 이름 라이브볼트 / 화면 영문명 Live Vault, 제공된 LV 원본 JPG로 런처·상단 로고 변경
- 사용자 지정 UI 코드 MainActivity.java·StudioTheme.java 유지
- 스피커 설정을 출력 설정 팝업으로 옮겨 스튜디오의 원래 카드 순서 유지
- 녹음 시작 설정을 하단 ⋯ 버튼으로 배치
- Noto Sans KR·Roboto Mono 실제 폰트 포함, Android 기본 버튼 그림자·글자 간격 제거
- 앱 ID·콘텐츠 URI·보관함 경로는 유지
- 원본 Figma 재조회는 계정 MCP 호출 한도로 제한됨; 픽셀 단위 대조는 미완료

1.3 standard/personal APK 빌드가 통과했다. 두 APK의 표시 이름·버전(4 / 1.3.0-checkpoint), 로고 원본 바이트, 포함 폰트·라이선스, 내부 캡처 구현/권한 분리 및 기존 1.2와 동일한 개발 서명을 검사했다. 공개 APK는 약 7.1 MB이며 개인용은 비공개 Drive 파일로만 전달한다.

새 에뮬레이터에서 PackageManager 준비까지 확인했으나 APK 설치·화면 캡처 도중 작업 환경 연결이 종료되었다. 재연결 뒤 소스와 산출물은 유지됐지만 에뮬레이터 프로세스와 실행 세션은 종료되어 360/412 너비의 최종 화면 캡처는 미완료다. 이번 버전의 실제 런타임/시각 검증을 통과한 것으로 기록하지 않는다.
