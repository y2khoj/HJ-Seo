## Android 런타임 검사

예약 녹음·스피커 기능 빌드(디자인 v2 통합 전)는 Android 11 x86_64 에뮬레이터에서 standard / personal 모두 다음 검사를 통과했다.

- 3초 예약 후 홈 화면으로 전환 → 백그라운드 녹음 시작
- 녹음 저장 → WAV 본문, MIDI 파일, 테이크 메타데이터 생성
- 5초 예약 취소 → 원래 시각이 지난 뒤에도 녹음/테이크 생성 없음
- 휴대폰 스피커 경로 열기 및 낮은 기본 게인 확인
- 배포용의 내부 오디오 캡처 권한/기능 제외 확인

앱 UI 갱신은 화면이 보일 때만 수행한다. 리버브 피드백 계수는 파라미터 변경 시에만 계산한다. 녹음 정상 종료 시 복구 루틴을 다시 실행하지 않는다.

디자인 v2 통합본은 두 APK·테스트 APK 빌드, 비공개 오버레이 없는 공개 소스 빌드, 호스트 DSP/예약/MIDI 시간축 검사를 통과했다. 통합본 에뮬레이터 재검사는 Android WindowManager 오류와 PackageManager 서비스 부재로 APK 설치 전에 중단되었다. 따라서 최신 통합본의 런타임 재검증은 남아 있다. 통합 UI의 실제 촬영·마이크/이어폰 품질과 시스템 오디오 캡처는 별도 기기 검증이 필요하다.

새 에뮬레이터에서 PackageManager 준비까지 확인했으나 APK 설치·화면 캡처 도중 작업 환경 연결이 종료되었다. 재연결 뒤 소스와 산출물은 유지됐지만 에뮬레이터 프로세스와 실행 세션은 종료되어 360/412 너비의 최종 화면 캡처는 미완료다. 이번 버전의 실제 런타임/시각 검증을 통과한 것으로 기록하지 않는다.
