90 BPM, 44.1kHz 스테레오로 실제 Java 스케줄러 이벤트를 C++ 엔진과 앱에 포함된 GeneralUser GS 1.44 SF2로 렌더링했습니다. 기본 프로젝트의 고정 seed와 각 트랙 볼륨 70%를 사용하며 건반은 뮤트되어 있습니다. 변경 전은 `ad22bd5`의 스케줄러를 같은 현재 렌더 엔진으로 실행한 결과입니다. 각 WAV에 FFmpeg의 1회 패스 `loudnorm=I=-20:TP=-1.5:LRA=11` 정규화를 적용한 뒤 192 kbps MP3로 변환했습니다. 정규화는 청취 비교를 돕기 위한 것으로 두 믹스의 원래 음량 차이를 평가하는 자료는 아닙니다.

합성 음원 비교 자료이며 사람이 직접 연주한 녹음이나 실기기 마이크 검사 결과가 아닙니다. 생성 과정은 [3.2 검증 기록](../../LIVE_VAULT_V3_2_VALIDATION.md)을 참고하세요.
